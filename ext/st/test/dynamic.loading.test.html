Testing fetch URL

YaiTabs can fetch data dynamically via the data-url attribute. Source: dynamic.loading.test.html 

<div
  data-yai-tabs
  data-swipe
  data-theme="dark"
  data-color-accent="secondary"
>
  <nav data-controller>
    <button
      data-tab-action="open"
      data-open="1"
      data-url="https://5elementsdesign.github.io/Speedtab/docs/data/dynamic.loading.test.html"
      data-url-refresh=""
      data-min-loading="400"
    >Dynamic 1</button>
  </nav>
  <div data-content>
    <div data-tab="1"></div>
  </div>
</div>
